# Measure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `repeat-o-scope measure` counts wasted turns per kind, in turns and tokens, and leads with the share of your usage they took.

**Architecture:**
- A new module `waste.py` reads the transcripts once and returns a `Measurement`: the total turns and tokens, plus one `Tally` per waste kind.
- A turn is one API call, i.e. one distinct assistant `message.id`. Claude Code writes one entry per content block, each with the same `message.id` and the same `usage`, so `usage` counts once per id.
- Each wasted turn is charged to exactly one kind, so the kinds add up to the total waste and the share stays at or below 100%.
- `fails` and `asks` keep their behaviour. Their classifiers (`_DENIED`, `_GO_AHEAD`) move from `cli.py` to `transcripts.py`, so `measure` and the reports use the same ones.

**Tech Stack:** Python 3.12+, stdlib only, existing `fire`. pytest. uv.

**Spec:** `docs/superpowers/specs/2026-11-17-budget-audit-design.md` (step 1, Measure)

## Open questions for Kimmo (the plan picks the default shown)

1. **"% of your 5-hour limit".** Transcripts don't carry the limit, and Anthropic doesn't publish it in tokens. Default: wasted weight divided by total weight over the window, labelled "of your usage". That equals the share of the limit if waste is spread evenly over 5-hour windows.
2. **Token weight.** Default: API price ratios, `input + 1.25 × cache_creation + 0.1 × cache_read + 5 × output`, in `waste._weight` as the one switch. Raw tokens (the plain sum of all four) are the secondary column.
3. **Context window.** Transcripts don't say whether a session ran with 200k or 1M. Default: the smallest of `(200_000, 1_000_000)` that fits the largest context seen in that session.

## Global Constraints

- Waste kinds, in this order everywhere (`waste.KINDS`): `refused_edit`, `reread`, `failed`, `denied`, `bare_yes`, `long_context`.
- Headline: the share of usage wasted. Raw tokens are a secondary column. € shows only with `--price`.
- `--price` is € per million weight units (an input-token equivalent). Without it there is no € anywhere, JSON included.
- `measure` reads transcripts only. Settings are `doctor`'s job, which is out of scope here, as are `compare`, baselines and the skill.
- Python `>=3.12`, no new dependencies. Repo rules: keyword-only arguments for 2+ parameters, private helpers, `_LOGGER`, `RepeatOScopeError` with the offending value in the message, negative tests first, tests through `tests/conftest.py`'s real-shaped transcripts.
- Work in a worktree at `.wt/measure` on branch `measure`. Run git from inside it, never `git -C` (Kimmo's `git` wrapper breaks `git -C <path> commit -m`). Commit there freely. Never push.

## Review Focus

1. **One API call, several entries.** A `tool_use` entry and a `thinking` entry with the same `message.id` count as 1 turn with its tokens once. Test in Task 1.
2. **Entries without `usage` or `message.id`** (synthetic messages, an old Claude Code version, a truncated last line) are skipped, not a crash. A failed tool call made from them is charged to nothing. Test in Task 1.
3. **Re-read after compaction or after an edit.** Reading a file again after the session was compacted, or after Claude edited it, is not a re-read. Test in Task 2.
4. **Two reads of different parts of one large file** (different `offset`/`limit`) are not a re-read. Test in Task 2.
5. **No transcripts in the window.** Markdown says 0 turns with no division by zero, and JSON has every kind at 0. Test in Task 5.
